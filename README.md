# Portfolio

Personal portfolio site for Neeraj Chormale — AI/ML engineer & backend developer.

Static, dependency-free: a single `index.html`, `styles.css`, and a small `script.js`
(colophon year, a live Pune clock, and scroll-triggered section reveals).

## Run locally

```bash
python3 -m http.server 4310
```

Then open <http://localhost:4310>.
