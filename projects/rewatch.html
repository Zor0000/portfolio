Watch recommendations

ReWatch

A content-based recommender for wristwatches that matches taste from both structured fields and free text. Feature engineering with one-hot encoding, scaling, and TF-IDF; cosine similarity surfaces the closest matches.

GitHub ↗

A closer look.

  • One-hot encoding and scaling represent the structured watch features.
  • TF-IDF represents the free-text descriptions.
  • Cosine similarity finds the closest matches using scikit-learn, pandas, and NumPy.

Built with

  • scikit-learn
  • pandas
  • NumPy
