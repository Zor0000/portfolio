Workout companion

Setzo

A native iPhone app for logging workouts and runs, tracking splits, and seeing progress. Local workout storage with optional Supabase sync, plus a Lock Screen Live Activity for sets and rest timers.

App details ↗ GitHub ↗

A closer look.

  • Log workouts and runs, track splits, and review progress in a native SwiftUI app.
  • Workout data stays local, with optional Supabase sync backed by PostgreSQL.
  • A Lock Screen Live Activity shows sets and rest timers. The companion app page also covers run and walk logging, personal records, and Fuel Buddy meal ideas.

Built with

  • SwiftUI
  • iOS
  • Supabase
  • PostgreSQL
