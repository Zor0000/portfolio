Conversational learning

Skillonomy

Built at Toshal Infotech

An AI-powered learning platform that helps business users learn AI through interactive conversations and personalized hands-on labs. The system combines a Neo4j knowledge graph for multi-hop concept reasoning with Milvus RAG for grounded answers.

YouTube demo ↗

A closer look.

  • A Neo4j knowledge graph connects AI concepts and their relationships for multi-hop reasoning.
  • Milvus retrieval grounds answers in source material, including questions outside the usual distribution.
  • LangGraph orchestrates conversations and lab generation; FastAPI provides the Python backend.

Built with

  • Python
  • FastAPI
  • Neo4j
  • Milvus
  • LangGraph
