Graph-based coaching

GymBuddy Agent

A graph-backed fitness agent that reasons over exercises and routines to coach you through a session. It walks an exercise knowledge graph in Cypher to plan and adapt workouts in conversation — deployed and live on Vercel.

Live ↗ GitHub ↗

A closer look.

  • An exercise knowledge graph represents movements and routines.
  • Cypher queries let the agent reason over that graph to plan and adapt workouts in conversation.
  • The web app is deployed on Vercel, with a live version and source repository.

Built with

  • Neo4j
  • Cypher
  • AI Agent
  • Vercel
